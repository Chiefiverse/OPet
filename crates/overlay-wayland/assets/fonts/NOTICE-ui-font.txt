所做的修改（OFL 定义下的 Modified Version）：
  1. 按同目录 ui-codepoints.txt 裁子集 —— **只删不改**：一个轮廓都没重画，也没加字。
     那份清单由 `python3 tools/subset_font.py --emit-codes` 从**代码里的函数**生成（l10n 四 locale
     的 `ui_strings()` ∪ 目录 30 个 `name`），不是人写的；`tests/font_assets.rs` 的两条相等门禁
     保证"清单 = 会画上卡片的东西"，缺字（卡片静默画 `?`）和多余字（白占常驻内存）都会红。
  2. 丢表 DSIG / BASE / GPOS / GSUB / VORG / vhea / vmtx，布局特性清空（UI 只用 hmtx 的 advance，
     不做连字与字距）。

  4. name 表 ID 0/1/2/3/4/6/8/13 重写：家族名改为 OPet UI ⇒ 满足 **OFL §3**（Modified Version
     不得沿用 Reserved Font Name "Noto Sans CJK"）；ID 0 保留原版权行并加 derived 声明。
  5. head.created / head.modified 钉成上游值 ⇒ 产物逐字节可重放。
  重放与验证：`python3 tools/subset_font.py --verify`（重建到临时目录并逐字节比对入库产物）。
